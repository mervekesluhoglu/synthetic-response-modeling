# Parameter Estimation in a Synthetic Response Model

A Python learning project exploring how measurement noise and initial parameter values affect parameter estimation in a simple temporal response model.

## Overview

I carried out this exercise to develop my understanding of convolution-based modeling and numerical optimization.

The notebook generates a synthetic response to a one-second stimulus using an exponential kernel. Two parameters are estimated with SciPy's `least_squares` function:

- **Gain:** controls the response scale.
- **Time constant:** controls how quickly the response decays.

The true gain is **1.5**, and the true time constant is **1.2 seconds**.

## Experiments

1. **Parameter recovery:** Estimate known parameters from one noisy synthetic signal.
2. **Measurement noise:** Compare estimates across three noise standard deviations—0.04, 0.15, and 0.30—with 50 repetitions per level.
3. **Initial values:** Fit one fixed noisy signal from six different starting points.

## Main Findings

- Increasing noise increased the variability and RMSE of the parameter estimates.
- Mean estimates remained close to the true values under the tested conditions.
- All six tested starting points produced the same estimates to the displayed precision for the fixed signal.
- Optimization completion alone did not guarantee accurate parameter estimates.

## How to Run

Open the notebook in Google Colab or a Jupyter environment with **NumPy, SciPy, and Matplotlib** installed. Run all cells from top to bottom.

No external dataset is required. Synthetic data are generated within the notebook, using fixed random seeds.

## Limitations

This exercise uses synthetic data rather than human physiological recordings. The same model is used to generate and fit the data.

The experiments do not establish performance on real physiological signals, uniqueness of the solution, or robustness to every possible starting point.
